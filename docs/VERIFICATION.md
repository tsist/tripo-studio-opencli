# 验证边界

## 历史实测

在Windows / OpenCLI1.8.7 / Blender5.2.1的有限样本中，HD单图/多视图/批量/文本与P2双输出回执、分件补全、三角/四边/SmartPoly重拓扑、UV精确保存、风格贴图、重绘预览、PBR、4K/8K服务、两种角色绑定与正确动作FBX分别具有对应证据。不是全部组合、服务永久支持或生成模型可编辑质量的保证。

代理一次真实8K Bridge具有唯一POST/UUID、下载字节、同receiver完成及内嵌8192²颜色图的保存冷读正例。观察器曾将OPTIONS误计重复，后同次只读回执补证，旧halt保留。修复后的classifier使用method/request_id判定；本地回放不等于另一次云实测。

用户选择的一轮本地语义保护复验固定Blender5.2.1/build9e2066aef7ef和保存帧。两个独立factory/disable-autoexec/offline进程分别读取发送前与收件文件；原15对象/5个Scene-ViewLayer、4材质/3图片的已捕获作者状态，以及12网格原可见与共同显现条件下的世界F32顶点字节/求值拓扑精确一致。53保护文件SHA保持。旧缓存matrix_world约4.371e-8严格失败继续保留，语义PASS不改签旧测试。该有界样本没有驱动/GN/集合实例，不推广通用保护。

## 当前公开发行适配

发布包只导出自研代码，路径变为环境变量，浏览器profile不再默认选用发布者ID；技能参考重写为公开说明，测试使用合成UUID。没有发布私有审计、真实账本、资产或前端bundle。公开适配没有执行新的Tripo云调用，历史资格与当前离线运行结果分开。

本次公开发行适配通过79项Python离线检查、16项假浏览器Bridge边界检查、11项回执分类检查；另验证7个适配器的安装/冲突拒绝及2个PowerShell脚本语法。套件覆盖真实临时账本CLI、单次提交回执、无价保存拒绝、现行9项UV身份夹具、6项动画选择、Bridge输入与OPTIONS分类。它们不证明真实账号登录、额度、当前DOM、下载服务或新用户Blender会话正常。独立只读源码审查未发现发布阻塞项。

官方技能quick_validate因隔离Python缺PyYAML未运行成功，未安装新依赖；有限frontmatter、相对引用、manifest身份/版本及所选公开文件的语法和敏感模式另行检查通过。

## 明确保留

- 无价重绘自动保存禁用；WebGL笔刷人工。
- 3MF仅XML网格语义，3dsMax预设仅静态，不提供目标应用完整验收。
- 当前8K Bridge只证明颜色图；另一个HD8K+PBR样本的Normal/RM为4K。
- 自动重连、任意参数组合、任意模型质量未验；P1quad等服务禁用组合不计通过。
- 旧预算事故、unknown/halt与严格矩阵失败不因新成功清除。

已结束的工具母任务采用用户明确接受限制的partial口径；发布版本也保留这些资格，不宣传“全部能力通过”。
