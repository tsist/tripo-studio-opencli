# 费用、数据与失败恢复

所有上传、导出和收费动作必须有当前任务的具体授权；开源发布不提供任何云预算或历史试用额度。按地区/账号隔离，默认国内com；海外仅显式请求。

账本schema2在提交前先写reserved/submitting，再作一次真实输入，回执丢失即unknown/halt。不因超时、手动成功或还有积分自动重试；旧占用不回收。后台恢复沿用同一export UUID，不能重新创建导出。

无可核服务价格或费用上界的重绘预览保存，在入口和共享提交层禁用，`--unpriced-apply-cap`不能解锁。其他具体批准的内部占用也不是服务商强制收费上限；余额净差额不自动归因于单笔价格。已超预留保留before/after/delta/reserved与未归因证据。

浏览器内身份令牌只用于已登录会话中的实际请求，不落盘。禁止公开Cookie、Bearer头、完整签名下载URL、原始network body、个人项目ID或参考图。报错/issue提供去标识的最小复现。

Bridge接续绑定现有profile/session/page，缺失、重复或输入前漂移即拒绝。eval只读；不写Pinia、DOM.click、合成DOM指针或hook fetch。允许helper通过已支持CDP发送真实鼠标输入。精确预算步骤必须在浏览器互斥锁范围内完成，Node helper本身不代替该锁或账本预留。

收件文件和原用户工程分开保存。不要关闭未知进程、抢占端口、覆盖输入或自动调整全局安全偏好。上传自有测试图与导出也会消耗操作/下载次数，不能因积分为0忽略。

此仓库不提供无人看管的通用WebGL笔刷或自动重连承诺；不安装/升级任何依赖。安全拒绝不是可以通过切换入口绕过的错误。
